# Handwritten Numbers

A simple handwritten digit recognition project built with Python and NumPy.

## What it does

It trains a small neural network on the MNIST dataset and predicts handwritten digits from **0–9**.

The project includes:

- Forward propagation
- ReLU activation
- Softmax
- Cross-entropy loss
- Backpropagation
- Gradient descent
- Model saving/loading
- Digit prediction

## Installation

```bash
pip install numpy scipy pandas Pillow
```

Place `mnist_train.csv` and `mnist_test.csv` in the project folder, then run:

```bash
python main.py
```
